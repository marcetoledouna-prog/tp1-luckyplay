Nosotros

LukyPlay un sitio para que todos puedan disfrutar de juegos clásicos de forma divertida.
Podrás probar suerte en tres juegos diferentes: cartas, dados y preguntas. Animate y divertite.

Tecnologías y recursos

  • HTML5, CSS3 (Flexbox) y JavaScript.
  • Imágenes de cartas y dados propias, creadas en formato svg.
  • Imágenes de fondo y logo propias, creadas en formato jpg y png.
  • localStorage y JSON para guardar récords y estadísticas.
  • API pública de Wikipedia en español para las imágenes y los datos de la Trivia de arte.
  • Git y GitHub para el trabajo colaborativo; GitHub Pages para la publicación.
  • Tipografías Righteous y Nunito de Google Fonts.
